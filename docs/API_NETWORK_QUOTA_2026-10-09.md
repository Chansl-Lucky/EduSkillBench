## 429已确认是套餐配额耗尽

通过当前可用代理对相同模型 `deepseek-v4-pro` 发起一条最小请求，接口返回 HTTP429：

```json
{
  "error": {
    "code": "AccountQuotaExceeded",
    "message": "You have exceeded the monthly usage quota. It will reset at 2026-10-17 23:59:59 +0800 CST.",
    "type": "TooManyRequests"
  }
}
```

Request ID：`02179154628252496de9f55314d9c1d75ac853e3e9cad7e3f975c`。

该原始错误明确指月度使用配额耗尽，不是RPM并发限流，也不能据此断言账户余额欠费。“周额度Key”是此前的俗称，当前这条Key的实际接口响应是月配额耗尽。重置时间为北京时间2026年10月17日23:59:59。换代理、端口或降低并发均不能恢复这项配额。
